# Безопасность InterPoint

Если вы обнаружили возможную уязвимость InterPoint или официального сайта, не публикуйте технические подробности в открытом обращении.

Сообщите о проблеме по электронной почте: [waterfaq@ya.ru](mailto:waterfaq@ya.ru).

Укажите версию InterPoint, версию Windows, краткое описание проблемы и безопасные шаги для её воспроизведения. Не прикладывайте пароли, ключи, персональные данные и другие конфиденциальные сведения.

Обычные ошибки расчётов и предложения новых возможностей можно отправлять через [GitHub Issues](https://github.com/Water-FAQ/InterPoint/issues).
