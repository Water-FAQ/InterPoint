# InterPoint

InterPoint — бесплатный калькулятор линейной, квадратичной и билинейной интерполяции и экстраполяции для Windows 10 и новее.

[Официальная страница](https://water-faq.github.io/InterPoint/) · [Скачать актуальную версию](https://github.com/Water-FAQ/InterPoint/releases/latest/download/InterPoint.zip) · [Все выпуски](https://github.com/Water-FAQ/InterPoint/releases)

## Возможности

- линейная и обратная интерполяция по двум точкам;
- квадратичная интерполяция по трём точкам;
- билинейная интерполяция по четырём угловым значениям;
- автоматическое определение интерполяции или экстраполяции;
- интерактивный график с масштабированием и перемещением;
- предупреждения для сомнительных расчётных случаев;
- подробный экспорт исходных данных, формул, проверок и графика в Excel;
- встроенная справка и горячие клавиши.

## Запуск

1. [Скачайте последнюю версию](https://github.com/Water-FAQ/InterPoint/releases/latest/download/InterPoint.zip).
2. Распакуйте архив в удобную папку.
3. Запустите `InterPoint.exe`.

Установка Python и Microsoft Excel не требуется.

## Безопасность

InterPoint не имеет цифровой подписи, поэтому Windows SmartScreen может предупредить о запуске неизвестного приложения. Контрольные суммы SHA-256 публикуются вместе с каждым релизом.

Исполняемый файл InterPoint v1.0.0 проверен с помощью [VirusTotal](https://www.virustotal.com/gui/file/0685c42fb659fcc0776ff8410918f7ebf885d155453a8ee5a3f4abb570f7c36a?nocache=1): 4 из 71 антивирусного движка сообщили о срабатывании, остальные 67 угроз не обнаружили.

## Конфиденциальность

Расчёты выполняются локально. InterPoint не передаёт разработчику исходные данные или результаты и не собирает телеметрию. При включённой автоматической проверке программа обращается только к официальному манифесту обновлений.

## Исходный код

Исходный код InterPoint не распространяется. В репозитории находятся сайт, документация и готовые выпуски программы.
